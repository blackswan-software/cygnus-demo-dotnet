# Cygnus Demo — eShop (.NET/C#)

Verify the supply chain of a .NET enterprise application. 10 NuGet packages with 55,000+ verified function tokens.

## Try it

```bash
git clone https://github.com/blackswan-software/cygnus-demo-dotnet.git
cd cygnus-demo-dotnet
curl -fsSL https://install.blackswan-software.ai | sh
cygnus -e csharp verify
```
